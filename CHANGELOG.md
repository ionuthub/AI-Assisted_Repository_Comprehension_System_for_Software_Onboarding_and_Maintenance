# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-01-03

### Added
- Centralized `Layout` component with global Header and Footer.
- `SEO` component for dynamic metadata management.
- Route-based code splitting (lazy loading) for optimized performance.
- `LICENSE.md` (MIT), `CONTRIBUTING.md`, and `CHANGELOG.md`.
- Page transitions using `AnimatePresence`.

### Fixed
- Redundant Header/Footer logic across all pages.
- Missing `@supabase/supabase-js` dependency.

## [1.0.0] - 2025-12-28

### Added
- Initial release of AI Code Tutor.
- GitHub repository analysis.
- Project idea generation.
- Local folder upload and analysis.
- AI-powered code explanations based on skill level.
