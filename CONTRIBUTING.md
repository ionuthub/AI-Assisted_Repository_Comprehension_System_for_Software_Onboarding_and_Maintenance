# Contributing to AI Code Tutor

First off, thank you for considering contributing to AI Code Tutor! It's people like you that make AI Code Tutor such a great tool.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct.

## How Can I Contribute?

### Reporting Bugs
* Check the existing issues to see if the bug has already been reported.
* If you can't find an open issue that describes the problem, open a new one. Include a clear title and description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements
* Open a new issue and describe the enhancement you would like to see.
* Explain why this enhancement would be useful to most AI Code Tutor users.

### Pull Requests
* Fill in the required template.
* Do not include more than one fix/feature per pull request.
* Follow the coding style of the project.
* Add unit tests for your changes.
* Ensure the CI/CD pipeline passes.

## Style Guide

### Git Commit Messages
* Use the present tense ("Add feature" not "Added feature").
* Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
* Limit the first line to 72 characters or less.

### Coding Style
* Use TypeScript for all new code.
* Use functional components and hooks.
* Follow the Prettier and ESLint configurations.

### Documentation Style
* Use Markdown for all documentation.
* Provide clear examples and use cases.

Thank you for your contribution!
