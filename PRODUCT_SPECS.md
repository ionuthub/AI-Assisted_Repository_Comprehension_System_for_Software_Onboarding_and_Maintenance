# Product Specifications - AI Code Tutor

## 🎯 Target Audience
1. **Self-Taught Learners**: Beginners trying to deconstruct complex open-source projects.
2. **Senior Developers**: Experts looking for quick summaries of unfamiliar logic in a new dependency.
3. **Educators**: Teachers looking to generate clean starter projects for their students.

## 🚀 Vision
To become the "Google Translate" for source code—making any codebase readable and understandable regardless of language or complexity.

## 📋 Core Requirements

### 1. Zero-Account Analysis
Users should be able to analyze any public GitHub repository without the friction of signing up.

### 2. Context-Aware Explanations
Explanations should not just be "what the code does," but "how it fits into the file" and "why it was implemented this way."

### 3. Adaptive Difficulty
The UI must provide a toggle to switch between "Explain like I'm 5" and "Senior Architect Review."

### 4. Direct GitHub Integration
The system must support private repositories via secure Personal Access Tokens (PAT).

## 🗺 Feature Roadmap

### Q1 2026: The "Enterprise" Foundation
- [x] Multi-language support (i18n).
- [x] SEO & Production readiness.
- [x] Documented Architecture & Governance.
- [ ] Unit & E2E Testing Suite.

### Q2 2026: Advanced Intelligence
- [ ] Multi-file context (Reasoning across the whole project, not just single files).
- [ ] Interactive Q&A (Chat with your codebase).

### Q3 2026: Ecosystem Expansion
