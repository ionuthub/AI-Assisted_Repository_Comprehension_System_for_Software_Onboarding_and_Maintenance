# Development process

**These documents were written in August 2026, after the study, from the milestone record in
Appendix E of the dissertation and from the repository history. They are a retrospective
description of phases that actually happened. They are not a contemporaneous agile artefact:
there were no daily stand-ups, no sprint tickets and no burndown charts, and none are invented
here.**

What is reconstructed is real: the phase boundaries are the milestones the project actually hit,
and the backlog items map to features that exist, were descoped, or were removed for stated
reasons.
