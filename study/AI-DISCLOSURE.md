# AI assistance disclosure

This is the repository-side record of AI assistance used in the dissertation project. It should agree with Appendix A of the dissertation.

The project uses AI in two different ways:

1. **As part of the artefact:** Google Gemini generates repository-grounded answers that are evaluated in the study.
2. **As research and development assistance:** AI tools also supported coding, testing, analysis, review, source work and writing.

The repository does not claim unaided authorship.

## Tools used

| Tool | Main use |
| --- | --- |
| Google Antigravity | Substantial generation of the initial React/TypeScript artefact |
| Claude Code | Implementation, debugging, refactoring, tests, analysis scripts and patch application |
| Claude chat | Technical discussion, protocol drafting, study-document revision and study-design review |
| CodeRabbit | Automated code review |
| ChatGPT | Technical discussion, debugging, scope and research-question refinement, source checking, editing and critical review |
| Perplexity | Candidate-literature discovery |
| NotebookLM | Organising and checking source material |
| Grammarly | Proofreading and language suggestions |

The researcher reviewed what was accepted and remains responsible for the submitted work.

## Development and analysis

The application, tests and analysis tooling were developed with AI assistance. Git authorship should therefore be read as repository responsibility, not proof that a file or commit was produced without AI help.

The accuracy-gate reference answers were AI-assisted and checked with tools against the study repositories. They are described as **tool-verified**. The researcher made the final binary gate verdicts.

The existing blind second marking was machine-produced and is not independent human confirmation.

## Participant study

The study used 12 participants. Participant exports are stored pseudonymised on University-managed storage.

AI tools were not used to fabricate participant answers, timings, questionnaire scores or other measurements. AI assistance was used for analysis support, checking, presentation and drafting. The researcher remains responsible for the method, study conduct, interpretation, limitations and conclusions.

## Sources and writing

AI tools supported literature discovery, source organisation, report structure, wording and review. Sources used in the dissertation were checked against the original publications before inclusion.
